# SEO記事・SNS制作プロンプト生成アプリ

Gemini APIを利用し、SEO記事の作成からSNS投稿文、画像・動画制作用プロンプトまで生成するStreamlitアプリです。画像・動画そのものは生成しません。

## 画像・動画の制作方式（2026-10-01更新）

`seo_content_strategy_studio` と同じ図解・動画プロンプト生成方式を採用しています。

- 画像：見出し・短い説明に、記事由来の要点ラベルや吹き出し・矢印・比較図を組み合わせます。文字は顔・手・重要な動作を隠しません。
- リール・TikTok：カルーセル9枚を01〜09の順で使用し、約55〜60秒の縦型動画にします。先に各画像を生成し、動画制作ツールへ渡してください。
- YouTube：1920×1080の横型専用に5〜7シーンを独立設計します。カルーセルの縦画像を引き伸ばしません。
- 表紙は5〜6秒。見出しと図解ラベルは静止表示し、サブテキストだけを編集可能な別レイヤーでタイプ入力風に表示します。
- ナレーションなし、明るく心地よいBGM、自然な改行、生成後の検品を指定します。以前の20項目の品質基準は、この方式と矛盾しない形で維持しています。

更新時は `app.py`、`social_tools.py`、`creative_quality.py` をGitHubで更新してください。生成済みの構成は自動変更されないため、SNS投稿文・制作プロンプトを再生成してください。追加のAPIキーは不要です。画像・動画の実生成と品質検査は制作先で行います。

## 3つのタブ

### キーワードからSEO記事

検索意図分析、H2・H3構成、H2単位のPREP法による本文執筆を順番に行います。体験談・独自ノウハウのメモ、途中再開、WordPress用HTMLに対応しています。

### URLから紹介記事

指定ページを読み込み、検索意図分析、構成作成、H2単位の本文執筆を行います。対象ページで確認できない数値・実績・口コミなどを作らないよう制限しています。

### 記事からSNS展開

完成記事または貼り付けた記事から、次の内容を生成します。

記事は直接貼り付けるほか、アプリからダウンロードした `seo_article.md` をそのままアップロードできます。`.md`、`.txt`、`.html`、`.htm` に対応し、`seo_article.md` 内の「完成した本文」だけを自動抽出します。

- X投稿文3パターン
- Facebook投稿文
- Googleビジネスプロフィール投稿文
- Threads投稿文
- Instagramカルーセル9枚の構成とキャプション
- Instagramリール、YouTube、TikTokの動画台本
- X、Facebook、GBP、Threads、リール表紙、YouTubeサムネイル、TikTok表紙の画像制作プロンプト
- Instagramカルーセル9枚それぞれの画像制作プロンプト
- Instagramリール、YouTube、TikTokの動画制作プロンプト
- 完成記事のH2・H3ごとの記事内画像制作プロンプト

制作プロンプトは、1件だけコピーしても成立する完成形です。画像ではイラスト領域とテキスト領域を完全分離し、プロのイラストレーター品質、人物・表情・背景・小物・光・配色・構図、日本語フォント、文字サイズ、自然な改行、安全余白、禁止事項まで指定します。

動画プロンプトには、冒頭2.5〜3秒の表紙、上下テキストの重複禁止、自然な日本語改行、穏やかなナレーション、インストBGM、発話中のBGM音量低下、映像・テロップ・音声の同期、最後の行動案内を含めます。SNS名・ロゴ・ユーザー名・保存ファイル名・透かしは動画内へ表示しません。

## APIキー

必要なのはGemini APIキーだけです。画像・動画生成APIキーは使用しません。

1. [Google AI Studio](https://aistudio.google.com/apikey)を開きます。
2. APIキーを作成してコピーします。
3. アプリ左側の「Gemini API設定」へ貼り付けます。

毎回の入力を省く場合は、Streamlit Community Cloudの **Settings → Secrets** に次を登録します。

```toml
GEMINI_API_KEY = "実際のGemini APIキー"
GEMINI_MODEL = "gemini-3.5-flash-lite"
```

## Streamlit Community Cloudへの更新

1. ZIPを解凍します。
2. GitHubリポジトリのファイルを新しいファイルへ置き換えます。
3. Streamlit Community CloudでアプリをRebootします。

## 注意事項

- 画像・動画は生成せず、制作プロンプトだけを作成します。
- 出力されたプロンプトを、お使いの画像生成AI・動画生成AIへ貼り付けて使用してください。
- 画像・動画生成サービスによって、日本語文字や音声への対応状況が異なります。
- AI生成文と制作物は公開前に、事実、誤字、文字化け、不自然な改行、医療表現を確認してください。
- 氏名、住所、症例などの個人情報は入力しないでください。
- 有料請求を設定しない限り、このアプリから自動的に有料枠へ切り替わることはありません。
